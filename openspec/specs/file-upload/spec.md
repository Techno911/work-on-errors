# file-upload Specification

## Purpose
Загрузка файлов проверяет настоящий тип по содержимому, а не по метке браузера.

## Requirements

### Requirement: Снифф типа по сигнатуре
При загрузке изображений (скриншоты записей, аватары) и документов система SHALL определять тип по первым байтам файла и MUST отклонять файл, чей реальный тип не входит в разрешённый список, независимо от заявленного Content-Type.

#### Scenario: Подделка под картинку
- **WHEN** клиент загружает SVG/текст с Content-Type `image/png`
- **THEN** ответ 400 «файл не является изображением», файл не сохраняется

#### Scenario: Настоящая картинка
- **WHEN** клиент загружает файл с валидной сигнатурой PNG/JPEG/WebP
- **THEN** файл принимается как раньше
