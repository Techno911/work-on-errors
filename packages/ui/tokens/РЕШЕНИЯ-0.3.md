## Как устроен источник правды с этой версии

1. **Переменные библиотеки Figma «ЧиП · Оболочка платформ» — единственный источник токенов.**
2. `tokens/выгрузка-figma.js` выгружает переменные библиотеки через Plugin API (инструмент
   `use_figma`) в `tokens/figma.json`. Формат выгрузки — контракт, описан в самом скрипте.
3. `scripts/tokens-build.mjs` строит из `tokens/figma.json` файлы `src/tokens.css` и
   `src/theme.css`. Руками эти два файла не правятся: `npm run check` пересобирает их и падает
   при любом расхождении.
4. Имя CSS-переменной задаёт код-синтаксис WEB переменной Figma. Переменная без код-синтаксиса
   или с именем вне пространства `--chip-*` в код не попадает и роняет сборку токенов.

## Решения по значениям

| № | Решение | Почему |
|---|---|---|
| 1 | Шкала кеглей 12 / 13 / 15 / 18 / 22 / 26 **+ ступень display 44** (600, межстрочное 1.1) | Заголовок-обещание панели входа: 44 уже у Бренд-платформы (эталон композиции) и UX Test Hub; у РО 28 и у Точки 26 были вне шкалы или не той ролью. Одна ступень, а не 28/30/33/36. |
| 2 | **Базовый кегль тела 13** (`body`) | У Бренд-платформы и UX Test Hub тело было 14 — вне шкалы; замер BP: 14 носили 3 элемента, 12-13 — 80. |
| 3 | **Одна роль «приглушённый на тёмном» = ink-400 `#a8a29e`**; `slate-400` и `login-on-inverse-muted` удаляются | Было два значения: `#9ca3af` (холодный slate) в меню и белый 45% на входе. Белый 45% на `#1a1a1a` даёт 4,47:1 — ниже AA 4,5 для мелкого текста. ink-400 даёт 6,9:1 и тёплый оттенок нашей палитры. |
| 4 | Полупрозрачные оттенки становятся именованными ролями: `overlay` (ink-900 · 50%), `hover` (ink-900 · 4%), `pressed` (ink-900 · 8%), `inverse-divider` (белый · 15%), `accent-on-dark-subtle` (amber-on-dark · 15%) | В собранном CSS 7-55 полупрозрачных литералов на платформу; значки пунктов на входе тонированы двумя разными цветами (`#d0650d/15` у РО, `#f2a165/15` у остальных). |
| 5 | Радиус `pill` 9999 входит в пакет | У BP и UX он был местным токеном. |
| 6 | Высота контрола: `control-height` 44 и `control-height-sm` 32 | Внутренние кнопки BP: 32 (самая частая), 40, 42; поля 40. Две ступени вместо четырёх: 44 для действий и форм, 32 для плотных мест (строки таблиц, панели инструментов). |
| 7 | Тени `shadow-raised` и `shadow-overlay` входят в пакет со значениями UX Test Hub | Тени были местными токенами UX и литералами у остальных. |
| 8 | Межстрочное задаётся парой к каждой ступени кегля (`--text-body--line-height`), разрядка надзаголовка 0.08em — токен | Местные `leading-*` и `tracking-*` были у всех четырёх. |
| 9 | Словарь один: платформа не объявляет собственных переменных кегля, радиуса, цвета, тени, межстрочного | Местных токенов в собранном CSS: РО 68, Точка 146, BP 22, UX 11. |

## Что сознательно не решено здесь

- Документная шкала отчёта Точки (78 / 44 / 33 / 25 / 19). Отчёт — отдельный жанр (печатный
  документ), решение принимается после переписи Точки: либо именованный набор `doc-*` в пакете,
  либо сведение к шкале.
- Тёмный режим. В коде и в Figma его нет как режима, есть роли тёмной панели; не заводим.
