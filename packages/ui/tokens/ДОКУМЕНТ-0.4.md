# Слой «Документ» · решение 23.09.2026, выпуск 0.4.0

Сдаточный документ (отчёт Точки, в перспективе документы Бренд-платформы и РО) — отдельный жанр:
тёмный холст, своя шкала, акциденция Oswald. До 0.4 он жил местными токенами Точки
(`--color-doc-*`, `--text-doc-*`, 48 переменных) и был дырой в системе: следующая платформа со
своим отчётом вырастила бы третий мир. С 0.4 он — слой пакета, источник — библиотека Figma.

Значения взяты из Точки (`origin/main`, `frontend/src/index.css`) как есть: вид документа у
клиента не меняется. Одно сознательное изменение — кегль ступенями вместо `clamp()`: резиновый
кегль на 1440 даёт 18,8, и принадлежность шкале проверить нельзя. Ступени — это максимумы и
минимумы прежних `clamp()`, поэтому края не сдвигаются; разница только на промежуточных ширинах.

## Код (0.4.0)

- Выгрузка поддерживает режимы: для коллекции с двумя режимами генератор пишет значения режима
  «Широкий» в `:root`, а «Узкий» — в `@media (max-width: 1023.98px) { :root { … } }`. Контракт
  выгрузки (`tokens/выгрузка-figma.js`) расширяется полем `значенияРежимов`.
- Тема Tailwind: `--color-doc-*`, `--text-doc-*` (+ `--line-height`), `--font-doc-display`,
  `--shadow-doc-accent` — имена, которыми Точка уже пишет классы, поэтому её миграция сводится к
  удалению местных объявлений.
- Шрифт Oswald (OFL) — файлы начертаний, которые использует Точка, внутри пакета, как Inter.
- Печать: `@media print` фиксирует широкий режим — в `styles.css`, не в токенах.
- Замки: кегли `--chip-doc-size-*` и шрифт документа входят в систему (перепись читает их из
  tokens.css), витрина получает страницу документа.
